Eco de API

O httpbin.org é um serviço público de teste: ele devolve o que recebe. Cada botão abaixo faz um pedido pelo Orkester, que leva a chave da API que você marcou para ela (a que atende eco). Esta página nunca vê o valor dela.

1 · Ler

GET /get com uma consulta. O eco mostra o que chegou lá.

2 · Escrever

POST /post com um texto seu. Só funciona se a API lê e escreve e você marcou “também escreve” para esta página.

3 · O token some

GET /headers devolve os cabeçalhos que o serviço recebeu, inclusive o da chave da sua API. O Orkester troca o valor por •••.

4 · Redirecionamento para fora

O serviço manda ir para outro site. O Orkester não segue (a chave não sai dos domínios da API) e devolve o 302.

Resultado

Nada pedido ainda.
